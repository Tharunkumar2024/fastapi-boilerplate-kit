# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 1.6.x   | Yes       |
| 1.5.x   | Best effort (upgrade to 1.6.x recommended) |
| < 1.5   | No        |

## Reporting a vulnerability

Please **do not** report security issues in public GitHub issues.

Send details to:

- **Email:** tharunkumar.developers@gmail.com  
- **GitHub:** [Private security advisory](https://github.com/Tharunkumar2024/fastapi-boilerplate-kit/security/advisories/new)

Include:

- A description of the issue and impact
- Steps to reproduce
- Affected versions
- Any suggested fix or mitigation (optional)

## Response

We aim to acknowledge reports within a reasonable timeframe and will coordinate on a fix and disclosure timeline when a vulnerability is confirmed.

## Generated applications

This project scaffolds applications that may handle authentication and user data. Operators of generated apps are responsible for securing deployment environments (secrets, TLS, database access, logging, and production configuration).
